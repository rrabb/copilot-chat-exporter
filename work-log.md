Pinned public VS Code source at commit `2d7c85305a7736f6285240b482e21275a4dfa642`, [`eventTranslator.ts`](https://github.com/microsoft/vscode/blob/2d7c85305a7736f6285240b482e21275a4dfa642/extensions/copilot/src/extension/chronicle/common/eventTranslator.ts), explicitly calls the delegated input a synthetic prompt produced by the parent's tool invocation and skips emitting `user.message` for subagent spans. Accordingly, count each verified subagent start as one delegated prompt, then add any separately persisted child-scope user-message prompts; count parent-scope user prompts only on the main row. The event log remains a private evolving format, so this is an evidence-based listing metric, not a claim that all delegated prompt text is represented by one event.
