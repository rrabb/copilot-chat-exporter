### 3. Unexpected default export

[CLI dispatch](src/cli.ts#L176) lists only when `--list` is present. Otherwise it calls [loadSession](src/index.ts#L31), which calls [resolveSession](src/session/locate.ts#L166). Resolution uses:

1. An explicit session UUID or journal path.
2. A UUID parsed from `VSCODE_TARGET_SESSION_LOG`.
3. The first session sorted by journal filesystem modification time.

With no environment target in the research process, calling `resolveSession()` directly, without rendering or writing an export, selected `d7b54756-14b7-443c-b4a5-2af39c787db6`, the exact session from the supplied unwanted export. This reproduces the newest-journal fallback. The environment of the user's earlier invocation was not captured, so its precise branch cannot be proved retrospectively.

The displayed listing date is UTC filesystem modification time, formatted by `toISOString()` in [CLI dispatch](src/cli.ts#L180), not recorded conversation activity. Therefore the listing's 23:43 and the export's recorded last-prompt time do not measure the same thing. The current default is not tied to the working directory or this chat.

### Optional resource checks

[Resource loading](src/session/enrich.ts#L35) reads complete resources as UTF-8 before rendering limits apply and suppresses read errors. Directory/read failures, absent optional resources, unsupported identifiers, binary payloads and intentional exclusion therefore need separate diagnostics. [Resource rendering](src/markdown.ts#L125) slices characters while labeling the slices as KiB, another instance of the byte-limit defect. No numeric future limit is approved by this audit.
